Browse a set of reading-practice images one at a time. Navigate with the on-screen arrows or your keyboard, and click an image to view it fullscreen.

To add images, drop `gen_N.png` files into `public/images/` and update the `IMAGES` list in `src/App.tsx`. Convert to JPEG (`sips -s format jpeg -s formatOptions 85`) to keep the repo slim.
