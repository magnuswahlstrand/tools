## Text Diff

### Description
A client-side tool for diffing two texts word-by-word. Users paste an original and a changed text, and the tool highlights added and removed words.

### Core Features
- Real-time word-level diff (LCS based)
- Added and removed word count display
- Client-side only (no server processing)

### Technical Requirements
- React for UI
- TypeScript
